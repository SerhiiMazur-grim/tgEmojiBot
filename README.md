Бот создаёт эмодзи-паки из чужих наборов и отдельных эмодзи и управляет ими.

Требования
Python 3.12.
Токен бота от @BotFather (желательно: владелец владеет Telegram Premium).
Отдельный аккаунт Telegram для создания паков.
api_id и api_hash с https://my.telegram.org/apps для подключения отдельного аккаунта через Telethon.

Подготовка
1. Запустить подготовку окружения.
Windows: setup_env.bat
Linux: bash setup_env.sh
2. Ответить на вопрос о виртуальном окружении. Enter создаст папку .venv. Ответ n оставит своё окружение, его нужно создать и активировать до запуска.
3. Дождаться установки пакетов. Скрипт показывает каждый пакет.
4. Ввести прокси, если Telegram недоступен напрямую. Формат: socks5://user:pass@host:port, socks4://host:port или http://host:port. Если прокси не нужен, нажать Enter. Скрипт проверит связь с Telegram.
5. Ввести токен бота. Скрипт проверит токен.
6. Ввести Telegram id администраторов через запятую.
7. Если скрипт попросит, открыть бота и нажать Старт. Скрипт проверит премиум-эмодзи в тексте и на кнопках.
8. Создать приложение на https://my.telegram.org/apps и ввести api_id и api_hash. Они нужны для официального подключения к Telegram, через него создаются стикерпаки и эмодзипаки.
9. Ввести номер телефона, код и пароль двухэтапной проверки, если он есть. Код может прийти на почту, в SMS или от имени Telegram в самом аккаунте. Скрипт показывает способ доставки, если Telegram его сообщил.
10. Прочитать предупреждение. Через 10 секунд нажать Enter. Старый файл .env будет очищен, новый будет записан.

До шага 10 файл .env не меняется. Если на шаге 10 ввести n или прервать подготовку, файл .env останется прежним, а введённые данные не сохранятся.
Все настройки записываются в файл .env. Сессия Telethon хранится там же и никуда не передаётся. Файл .env нельзя передавать другим людям.
Подготовку можно запускать повторно. Сохранённые значения остаются, если нажать Enter.
Подробности ошибок записываются в файл error.txt.

Запуск
Windows: start.bat
Linux: bash start.sh
Если используется своё окружение, его нужно активировать до запуска.

Файлы
bot.py - запуск бота.
start.bat, start.sh - запуск бота.
setup_env.py - подготовка окружения.
setup_env.bat, setup_env.sh - установка пакетов и запуск подготовки окружения.
requirements.txt - зависимости.
app - код бота.
.env - токены и настройки, создаётся при подготовке.
error.txt - подробности ошибок подготовки, создаётся при первой ошибке.
bot.db - база данных, создаётся при первом запуске.

Ограничения
С одним токеном можно запускать только одну копию бота.
Паки принадлежат аккаунту Telethon. После смены аккаунта паки старого аккаунта нельзя изменять через бота.
